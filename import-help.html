Add a generation

The gallery rebuilds and deploys after a push to main. New images start as unreviewed studies.

From any computer

  1. Download or export the image from Nautilus or your generation tool.
  2. Upload images into the public gallery repository’s incoming folder ↗. Sign in to GitHub with repository access.
  3. Commit the uploaded files to main. GitHub Actions rebuilds and deploys the gallery automatically.

This static page cannot upload directly to your repository. No GitHub tokens are stored in the browser.

From this project on your Mac

Import an exported image, rebuild, then publish:

rtk proxy python3 experiments/gallery/import_generation.py /absolute/path/image.png
rtk proxy python3 experiments/gallery/publish.py

You can also save images directly in experiments/gallery/incoming/. Optionally add image.png.json with title, source, description, category and status. Images uploaded through GitHub are public. Do not upload private prompts there. The local importer stores prompts only in the private project metadata.

When asking the design agent to generate a new trial, ask it to import the final output and publish the gallery. A generation still inside Nautilus is not automatically downloaded by this gallery.
